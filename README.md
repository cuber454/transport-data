# Данные приложения «Транспорт» (Минск)

Здесь лежит база, которую приложение скачивает само при проверке по Wi-Fi:
`base.json` (маршруты и остановки), `suburban.json`, `extras.json`, `metro.json`,
`addresses.json` и `version.json` с версией и контрольными суммами.

Приложение при запуске раз в сутки спрашивает `version.json` и, если версия новее,
скачивает файлы, сверяя размер и sha256.

## Как обновляется

Обновление запускается **на компьютере автора** (задача планировщика Windows,
`инструменты\install-monthly-task.ps1` в основном проекте): 1-го числа каждого месяца
в 05:00. Скрипт собирает маршруты, остановки и названия, сверяет контрольные суммы
и заливает новую версию только при изменениях.

Облачные запуски GitHub для этого не годятся: сайт Минсктранса не отвечает с машин
GitHub (проверено 07.11.2026 — адрес находится, соединение висит и обрывается по
таймауту). Скрипты в `tools/` оставлены для ручных запусков и на случай, если доступ
когда-нибудь появится.
