# Транспорт — приложение для незрячих пассажиров Минска

Показывает, когда придёт автобус, троллейбус или трамвай, и называет остановки, мимо которых
ты едешь. Управляется экранным диктором, рассчитано на невизуальное использование. Работает
без интернета, обновляется само.

**Скачать и поставить:** https://cuber454.github.io/transport-data/

Здесь же лежат файлы базы: `base.json` (маршруты и остановки, город и пригород вместе),
`suburban.json`, `extras.json`, `metro.json`, `addresses.json` и `schedules/00.json` …
`schedules/15.json` (расписания остановок). Рядом `version.json` — по нему приложение
понимает, что вышло новое. Руками эти файлы трогать не нужно.

- Версия программы: 0.8
- Данные: 2026-11-18
- Телефон: Android 8 и новее

## Откуда данные

- Маршруты, остановки, время прибытия и расписания — с сайта «Виртуальное табло»
  [minsktrans.by](https://minsktrans.by/lookout_yard). Приложение неофициальное, к сайту
  не относится и не выдаёт его данные за свои.
- Адреса домов, карты и станции метро — © участники [OpenStreetMap](https://www.openstreetmap.org/copyright),
  данные распространяются по лицензии ODbL (Open Database License). Адреса собраны из выписки
  OSM, метро — из выписки OSM и остановок города.

Если правообладатель захочет, чтобы данные здесь не лежали, — напиши автору, уберём.

## Что внутри и как это устроено

- `version.json` — список файлов, их размер и SHA-256. Приложение качает только то, что
  прислал сервер, и сверяет размер и контрольную сумму каждого файла.
- Базы пересобираются скриптами проекта (`build-base.mjs`, `build-region.mjs`,
  `build-schedules.mjs`, `publish-data.mjs` и другими). Версия данных — дата сборки.
- Расписания приходят вместе с данными: с 18.11.2026 в версии 21 файл, а не пять.

Официальное приложение по всей стране — [«Транспорт BY»](https://play.google.com/store/apps/details?id=by.iba.transport).
