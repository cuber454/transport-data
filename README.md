# Транспорт — приложение для незрячих пассажиров Минска

Показывает, когда придёт автобус, троллейбус или трамвай, управляется голосом и рассчитано
на экранный диктор. Работает без интернета, обновляется само.

**Скачать и поставить:** https://cuber454.github.io/transport-data/

Здесь же лежат файлы базы расписаний (`base.json`, `suburban.json`, `extras.json`) и
`version.json` — по ним приложение понимает, что вышло новое. Руками эти файлы трогать не нужно.

- Версия: 0.6
- Размер: 15,8 МБ
- Телефон: Android 8 и новее
- Написать автору: [@Cuber456](https://t.me/Cuber456), cubiccubic2@gmail.com

Официальное приложение по всей стране — [«Транспорт BY»](https://play.google.com/store/apps/details?id=by.iba.transport).
